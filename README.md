# Tenacore New — enhanced stakeholder review

A multi-page HTML website for Tenacore's digital and IT services, revised using the supplied visual reference and plain-language content.

Open index.html locally, or upload all HTML files and assets/ to your hosting provider's web root. Keep the folder structure intact. No build or installation is needed.

## Pages

Home; About Us; Products; Billing Solutions; Network Solutions; Services; Portfolio; Contact Us; enquiry follow-up; seven individual portfolio project pages; and a visual design-system reference.

## Shared files

- assets/design-system.css: colours, typography, readable controls, spacing, buttons, and common foundations.
- assets/site.css: page layouts and responsive behaviour.
- assets/site.js: navigation, product dropdown, portfolio filtering, hero tabs, and enquiry routing.
- assets/config.js: optional direct-submission endpoint.
- design-system.html: visual style reference.
- DESIGN-NOTES.md: page narrative, changes, checks, and image provenance.

## Enquiries

Without a configured endpoint, the form opens an email draft to info@tenacore.com. The visitor must send that email. No delivery confirmation is shown.

For direct submission, configure assets/config.js with a form endpoint appropriate for your host/provider and adapt the request/response handling as needed. Do not place secret credentials in client-side JavaScript. Test end-to-end delivery after configuration. Only a successful configured submission redirects to thank-you.html; direct visits to that page show neutral contact information.
